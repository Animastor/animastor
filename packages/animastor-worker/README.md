# Animastor Worker (`animastor-worker`)

Standalone GPU compute agent for the Animastor pipeline. Runs a local
ComfyUI instance and executes generation jobs dispatched by the Animastor
GPU Hub over the frozen **Job Protocol v2**.

The package boundary is `worker/`:

```
worker/
├── worker/            runtime bundle (the only shipped artifact)
│   ├── worker.cjs                     entrypoint — node worker.cjs
│   ├── worker-env.cjs                 zero-dep .env loader
│   ├── worker-cleanup.cjs             per-job artifact cleanup
│   ├── worker-cleanup-journal.cjs     crash-safe cleanup journal
│   ├── job-protocol-v2.cjs            GENERATED from @animastor/contracts (do not edit)
│   ├── package.json                   canonical bundle version (2.1.0)
│   └── .env.example                   configuration template
├── tests/             package-owned zero-dependency tests (not shipped)
│   ├── harness.cjs / run-all.cjs
│   ├── worker-env / cleanup / journal / protocol / package tests
│   └── standalone.test.cjs            boot smoke from a clean copy
└── tools/
    └── sync-protocol.cjs              regenerates job-protocol-v2.cjs from contracts/
```

## Runtime requirements

- **Node ≥ 18** (global `fetch`); the bundle has **zero runtime npm
  dependencies** — no `npm install` is needed, ever.
- A local ComfyUI HTTP endpoint (`COMFY_PORT`, default `8188`).
- `ANIMASTOR_WORKER_TOKEN` (fail-closed: without it the worker refuses to start).

## Run standalone

```sh
cp worker/.env.example worker/.env   # set HUB_URL, ANIMASTOR_WORKER_TOKEN, WORKER_TYPE, WORKER_ID
cd worker && node worker.cjs
```

Or via the operator script (`worker/start-worker.sh` at the repo root —
installs Node if missing, detects the ComfyUI port, starts the daemon).

## Install from npm

```sh
npm install animastor-worker
```

Then configure and run:

```sh
cp node_modules/animastor-worker/.env.example .env
# edit .env — set HUB_URL, ANIMASTOR_WORKER_TOKEN, WORKER_TYPE, WORKER_ID
node node_modules/animastor-worker/worker.cjs
```

The package has zero runtime dependencies.

## Job Protocol v2 (contract)

The wire protocol is frozen and owned by the canonical package
`@animastor/contracts` (see `contracts/` and
`docs/architecture/JOB_PROTOCOL_V2.md`). Because the worker bundle ships
with zero runtime npm dependencies to GPU machines without a registry, it
carries an **explicitly generated byte-exact copy** of the canonical
implementation (`worker/job-protocol-v2.cjs`). It is not a second
implementation — the copy is parity-guarded:

```sh
node tools/sync-protocol.cjs --check   # verify parity (CI + tests)
node tools/sync-protocol.cjs           # regenerate after a canonical change
```

Guards: `worker/tests/job-protocol.test.cjs` (package level) and
`backend/tests/architecture/phase9d-worker-package.test.js` (repo level,
includes a negative control).

## Tests (zero dependencies)

```sh
node tests/run-all.cjs        # from worker/ — unit + parity + standalone boot smoke
```

## Delivery channels (all serve the same bundle)

1. `GET {HUB_URL}/worker-bundle` — hub publishes this directory as a
   deterministic tar.gz (sha256 at `/worker-bundle/sha256`).
2. Animastor installer — copies the manifest file list into the worker dir.
3. Manual copy of `worker/worker/` to any machine with Node ≥ 18.

## Architecture invariants (guarded)

- Zero runtime npm dependencies; requires only node builtins + files inside
  the bundle (no requires reaching into backend/gpu-hub/frontends/contracts).
- No Redis/PG access — the hub HTTP contract is the only interface.
- Version bumps here are the canonical worker bundle version (surfaced by
  the hub artifact and the installer compatibility resolver).
