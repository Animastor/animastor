# Naming Rules

## IDs
- Format: `snake_case`.
- Use English only.
- Must be unique within their domain (characters, scenes, locations, chapters).
- Examples: `main_protagonist`, `forest_scene_1`, `old_mansion`.

## Titles and Labels
- Can be in any language (typically the user's language).
- Should be descriptive and concise.
- Scene titles: max 80 characters.
- Character names: max 50 characters.
- Location names: max 60 characters.

## File Paths
- Use `kebab-case` for asset files.
- Audio: `scene_{id}_audio.mp3`
- Image: `scene_{id}_image.webp`
- Video: `scene_{id}_video.mp4`
