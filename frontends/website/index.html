What is Animastor?

Animastor turns written stories into animated storytelling. You import a text, the platform parses it into scenes, and a generation pipeline produces the image, audio and video layers of each scene.

It is built for bring-your-own resources: you configure your own AI provider (any OpenAI-compatible API) and, for GPU generation, connect your own GPU as a Private Worker. Animastor provides the application, orchestration and pipeline — the compute is yours.

Getting Started

  1. Create an account — or use the app directly; registration is also available inside the application.
  2. Open the application at app.animastor.in.
  3. Configure your AI provider in Settings → AI Providers (guide).
  4. Connect a Private Worker if GPU generation is required (guide).
  5. Import a story and generate your first scenes.
